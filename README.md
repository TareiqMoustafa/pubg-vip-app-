# Lader Tareiq

تطبيق **Lader Tareiq** للتحقق من التراخيص عبر السيرفر، ومزامنة إعدادات وحزم **OTA**، وتحميل ملفات الموارد والباتشات والتحقق من بصمة `SHA-256` بشكل آمن ومستقر.

## هيكل المستودع
- `.github/workflows/build-apk.yml` — سير عمل تلقائي لبناء ملف **APK** على GitHub Actions ورفع الناتج كـ Artifact.
- `pyproject.toml` — إعدادات الحزمة وبناء Android عبر **Flet**.
- `src/config.py` — ثوابت التطبيق، رابط السيرفر، المهلات، وألوان الواجهة.
- `src/state.py` — حفظ الحالة محلياً بطريقة ذرية (`state.json`) وإدارة سجل العمليات.
- `src/api.py` — التواصل مع السيرفر (`/api/health`، `/api/app-config`، `/api/ota-bundle`، `/api/verify`) وتوليد معرّف الجهاز وفحص `SHA-256`.
- `src/installer.py` — تحميل الحزم والتحقق من `SHA-256` وفك ضغط `.zip` بأمان.
- `src/ui_components.py` — عناصر الواجهة الموحدة (بطاقات الأقسام، عدادات الحالة، ألوان الحالات).
- `src/main.py` — الواجهة الرئيسية والتشغيل التفاعلي في خيوط خلفية.

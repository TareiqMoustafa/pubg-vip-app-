# PUBG VIP Manager (التطبيق)

تطبيق Flet لأندرويد: يتحقق من كود التفعيل عبر سيرفر التراخيص، ثم يحمّل الباتش ويثبّته، ويعرض مدة الاشتراك ويحذف الباتش.

## المميزات (1.4)
- واجهة نيون بأربعة تبويبات: الرئيسية · الأدوات · السجل · الإعدادات.
- شريط تحميل بالنسبة والحجم والسرعة، والتحقق من سلامة الملف بـ SHA-256 إن وضعته في لوحة التحكم.
- «ما الجديد» لكل باتش، وتنبيه قبل انتهاء الاشتراك بـ 3 أيام.
- فحص الجاهزية ونسخ تقرير للدعم، وسجل نشاط محلي.
- تحديث الباتش تلقائياً (خيار للمستخدم) أو إلزامياً (من اللوحة).
- أي خطأ غير متوقع يظهر كرسالة بدل أن ينهار التطبيق.

## الهيكل
```
src/main.py       الواجهة
src/config.py     الإعدادات (نسخة التطبيق، رابط السيرفر، مسارات اللعبة)
src/api.py        التحقق من الكود + معرّف الجهاز + إعدادات التطبيق العامة
src/installer.py  التحميل + النقل + الحذف + الأمر اليدوي (Shizuku)
src/state.py      حفظ الكود ورقم الباتش المثبّت وسجل النشاط محلياً
```

## أين أضع رابط الباتش؟
من لوحة التحكم على السيرفر: `https://<سيرفرك>.vercel.app/admin` ← **الإعدادات** ← **ملف الباتش** ← «رابط التحميل المباشر».
يُطبَّق فوراً على كل المستخدمين بدون إعادة بناء التطبيق، ويصل للتطبيق بعد التحقق من الكود فقط.
(`PATCH_DOWNLOAD_URL` في `config.py` احتياطي فقط.)

## تحديث الباتش
1. ارفع الملف الجديد وضع رابطه في اللوحة.
2. غيّر «رقم الباتش» (مثلاً من 1 إلى 2).
3. فعّل «تحديث الباتش الإلزامي» إن أردت أن يثبّته التطبيق تلقائياً عند الفتح، وإلا يظهر للمستخدم زر «تحديث الباتش».

## تحديث التطبيق نفسه (إلزامي)
ارفع الـ APK الجديد، ثم في اللوحة: «أقل نسخة تطبيق مسموحة» = النسخة الجديدة، و«رابط تحميل التطبيق الجديد» = رابط الـ APK.
النسخ الأقدم تُمنع وتعرض زر التحميل. ارفع `APP_VERSION` في `config.py` و`version` في `pyproject.toml` مع كل إصدار.

## البناء
ادفع الكود إلى `main` ثم نزّل الـ APK من Actions ← آخر تشغيل ← Artifacts.

## التشغيل محلياً
```
pip install "flet[all]==1.0.*" httpx
flet run src/main.py
```
